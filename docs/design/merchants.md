# Merchants
- **Merchant Key Rule.** A merchant is `merchantFor(description).key`: lowercase, cut at the first `*`, the first token with three or more digits, then a trailing country and city, `.nl` stripped. It must stay a substring of the lowercase description because it is used verbatim as a rule pattern; under 4 characters it never gets a rule.
- **One rule per shop.** The sheet creates the rule with `POST /rules` and the key (never `create-rule`, which pins the whole description), then settles only that merchant's unconfirmed purchases. Confirmed history is never recategorised.
- **The rule button is vermilion** only when the shop is sorted one way; plain when it is sorted several ways or the key is too short.
- **No zero for a missing month:** a financial month without bank data shows an empty track and a dash, never a zero or a bar.
- **The sheet is modal for real.** While open, `#root` is `inert`, `html` has `overflow: hidden` (the stable scrollbar gutter keeps the page from shifting), Tab and Shift+Tab wrap between the sheet's first and last control, and `overscroll-behavior: contain` stops a wheel at the sheet's end reaching the page. Close restores all of it before focus returns to the row that opened it; keep that order. A picker (CategorySelect) is portaled to `body`, so the wrap ignores focus outside the sheet.
- **The sheet keeps its place.** `min-height: min(28rem, 88svh)` from the first frame, and the title is the clean shop name from the first frame (the provider passes `merchantFor(description).name`, never the lowercase key). Focus parked on the sheet itself shows no ring; the controls inside keep theirs.
- **The header is pinned.** `.sheet.mer .tx-sheet-head` is sticky at `top: -1.3rem` (the sheet's own top padding; `top: 0` would pin it 1.3rem down) on `--card` with a `--line` hairline. `scroll-padding-top` keeps a focused control from hiding under it.
- **Ranked rows are `.cat-row.mer-row`.** Rules for the row (wider than its text so the lift and ring have room, `--r-row`, `--raised` + `--raise-sm` lift on hover devices only, chevron after the amount) live on `.mer-row`; `.cat-row` is shared with Month.
- **Merchants scrolls the switch up on a phone**, once the list is drawn (`scroll-margin-top` on `.mer-views`; smooth unless reduced motion). It goes only as far as the page's height allows: with few rows it stops short of the top, which still shows the list.
- An existing rule's well (`.mer-rule.is-set`) puts the sentence left and "Change in Setup" right; the new-rule form well stays stacked.
